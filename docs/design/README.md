# Design screenshots

Reference renders of the move to **Égide**, the shared design system of AETHRYON (source:
[`packages/design`](../../packages/design/README.md)). They are kept to compare versions and to review changes; they
are not used by any build.

| Folder | Contents |
|---|---|
| [`captures/avant/`](captures/avant) | The interfaces **before** Égide: public website, personal space and Control Center, Desktop, extension popup, Premiere panel, Setup |
| [`captures/prototypes/`](captures/prototypes) | Static mock-ups of the design directions that were compared before choosing Égide |
| [`captures/egide-v2/`](captures/egide-v2) | Égide v2 on the website, Desktop, extension and mobile layouts, in each official theme and at several widths, plus contact sheets (`planches/`) |

`mesures.json` next to the screenshots records the automated checks of each render (horizontal overflow,
elements outside the viewport, motion setting, axe-core violations, console errors).

All data shown is **fictitious or from test accounts** (`*.preprod.test` addresses on a pre-production instance,
sample media and names in the browser test harnesses). Desktop renders come from a browser harness, not from Windows.

The screenshots show the AETHRYON brand, which is not covered by the code license (see
[`TRADEMARK.md`](../../TRADEMARK.md)).
